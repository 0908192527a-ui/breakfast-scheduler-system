# 早餐店自動排班系統

這是一個可直接執行的純前端早餐店排班系統，適合店長管理員工、設定排班規則、休假、每日人力需求，以及自動排班與手動修改。

## 功能概覽

- 員工管理：新增、編輯、停用、刪除
- 正職 / PT 分類設定
- 每週最低需求與目標人數設定
- 特定日期覆寫人力需求
- 休假類型與指定休假管理
- 不可同日休假組合
- 自動排班演算法（決定性、可控）
- 月班表手動修改
- 缺人與排班問題檢查
- 本地資料儲存（localStorage）
- 匯出備份 / 還原備份
- 列印與匯出 CSV / 個人班表

## 專案結構

- `index.html`：主頁面
- `style.css`：響應式樣式
- `app.js`：主要應用邏輯
- `server.js`：靜態伺服器
- `package.json`：啟動腳本

## 執行方式

### 方案 1：使用 Node

```bash
npm start
```

打開瀏覽器：

```text
http://localhost:8000
```

### 方案 2：直接開啟檔案

也可以直接在瀏覽器打開 `index.html`，但建議使用本地伺服器以確保路徑與資源載入更穩定。

## 主要使用流程

1. 在「員工管理」頁面新增員工與設定可上班條件
2. 在「排班設定」頁面指定每週人力需求與特殊日期
3. 在「休假管理」頁面新增休假假別與指定休假
4. 進入「自動排班」頁面，點擊產生班表
5. 在「月班表」頁面檢視並手動修改
6. 在「缺人與排班問題」頁面處理缺人與重疊問題
7. 透過「資料備份」匯出或還原資料

## 主要測試情境

已完成與驗證的核心測試：

- 正常月份排班
- 指定休假排除
- PT 工作日限制
- 連續上班限制
- 跨月連續上班判斷
- 缺人提醒
- 手動修改後重新檢查
- 頁面重整後資料保留

## 資料儲存與備份

- 系統資料會自動保存到瀏覽器的 `localStorage`
- 可透過「資料備份」匯出成 JSON 檔案
- 也可從備份檔案還原

## 備註

此版本為第一個可用版本，目標為提供完整可操作流程，並保留後續擴充雲端同步或資料庫升級的可能性。
